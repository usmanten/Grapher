# Sample app

A small Next.js App Router project used by Grapher's tests. It is never installed or run; Grapher only reads its source.

It covers the patterns Grapher detects: pages and layouts, components displayed by pages, API routes (including a dynamic `[id]` route), client `fetch` calls to those routes, a server component reading the database directly, a server action, Prisma, Resend and Stripe, environment settings, and a route group.
