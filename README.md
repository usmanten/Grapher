# Grapher

See how your Next.js project fits together.

Grapher maps a codebase into an interactive graph of files, pages, API routes, databases and outside services, with a short plain-English explanation for every connection. It is built for students and anyone learning to build with modern frameworks, and it never shows the value of a secret.

> **Status:** early development. Not ready for use yet.
